近期想尝试一下安卓 kernel 的 kgsl 模块编译以及模拟。

实验环境

基于 Debian 12，clone 了 android-kernel repo 来进行试验。
由于Android 14以后不再支持 ./build.sh，我们这里集中学习如何使用 Bazel 来进行定制化编译。

编译内核模块以及 DTB

in tree kernel modules

需要在内核 BUILD.bazel 的 kernel_build 中设置添加 modules_outs 属性。

external kernel modules

需要额外定义 kernel_module 。要为 build.config 中的 EXT_MODULES 变量中的每一个模块创建 kernel_module 编译目标
kernel_module 中 kernel_build 属性为 自定义内核，或者 common 通用内核 //common:kernel_aarch64
outs 目录可以在编译过程中根据报错提示来进行更改。
设置 kernel_module 的 visibility 从而 kernel_modules_install 可以看到
如果 模块 依赖于其他模块，设置 kernel_module_deps。
如果模块依赖于其他路径的头文件，需要添加 filegroup，然后向 srcs 添加 headers。

定义 depmod 目标

定义 kernel_modules_install 目标。其包含所有 external kernel modules。其等价于 make modules_install 。

定义目标来构建所有启动镜像

kernel_image 宏会制作可刷写的分区镜像。

定义发行版目标

定义 pkg_files 和 pgk_install 目标，其包含了想要放置在 distribution 目录的目标。
